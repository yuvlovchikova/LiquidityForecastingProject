# Прогнозирование рыночной ликвидности

Учебно-исследовательский проект (2021) по прогнозированию рыночной ликвидности на высокочастотных данных BTC/USD с помощью рекуррентной нейронной сети.

Ноутбук начинается с сырых данных отдельных сделок, строит временной ряд состояния рынка и обучает LSTM-модель для прогнозирования. В репозитории также сохранён сопроводительный отчёт.

## Стек

Python · pandas · NumPy · Matplotlib · PyTorch · LSTM · Jupyter

## Данные и моделирование

Ноутбук использует сделки BTC/USD с биржи Bitstamp. Исходный набор содержит около 1,45 млн транзакций за IV квартал 2020 года: временные метки, цену, объём сделки и направление buy/sell.

Пайплайн включает:

1. очистку транзакционных данных и разведочный анализ;
2. построение временных рядов и подготовку признаков;
3. формирование последовательностей для рекуррентной модели;
4. собственную реализацию LSTM-модели на PyTorch;
5. обучение с MSE-функцией потерь и оптимизатором Adam;
6. оценку и визуализацию прогнозов.

## Файлы

- `Liquidity forecasting.ipynb` — полный исследовательский процесс от сырых транзакций до LSTM-прогноза;
- `Отчёт_Ловчикова_Юлия.pdf` — отчёт по проекту.
